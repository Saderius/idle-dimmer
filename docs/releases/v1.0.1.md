## Highlights

- Native Windows acrylic follows the colours behind the flyout, with a distinct darker footer.
- The flyout moves as one window, including its border and shadow, and opens behind the taskbar.
- Tile and clock glyphs use thinner, antialiased strokes closer to the Windows reference.
- Scroll over the timeout slider row to adjust the delay one minute at a time.

## Fixes

- Reworked display-off session handling after a report of monitors cycling on and off.
  Manual display-off now waits five seconds, sends one Windows screen-off request, and
  separates that session from idle checks. General manual off/wake behavior was confirmed
  on the development desktop; Surface-specific behavior still needs testing.
- Removed the unintended global keyboard shortcut and temporary diagnostic logging.
- Released the native UI worker when the flyout closes.

## Notes

The slider-wheel interaction and exact visual parity still need user review. Entrance motion
is improved, with further smoothness polish planned. This release does not yet include an
in-app updater; update checks and installation are a separate follow-up.
